# `enterprise_ring/`

The TLS ring: `enterprise-stages::tls` carries Pulse and envelope frames across NATs, firewalls and middleboxes as HTTPS. Its TCP mode works, TLS 1.3 on rustls with the sender verifying the server's certificate and name; its DTLS and QUIC-tunnel modes return `IntegrationDeferred`, so the crate's status is partial. `enterprise-hub` composes it, and `enterprise-core` and `enterprise-functions` are empty placeholders that keep the four-crate shape, because the ring's one primitive carries session state and is a stage. Depend on `enterprise-hub`. The book's page is [enterprise ring](https://pulse-mesh.net/docs/profiles/architecture/rings/enterprise_ring.html); the crates are in the generated [crate index](https://pulse-mesh.net/docs/profiles/reference/crates.html).
