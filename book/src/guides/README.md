<p class="pm-kind"><b>Part opener</b> · for people who already run Pulse Mesh</p>

A guide does not teach. It names the task, states what you need, and gives the steps in order, with the result you should see after each one. Background belongs in the [Concepts](../explanation/README.md) part and exact facts in the [Reference](../reference/README.md) part; a guide links to both instead of repeating them.

The guides are in the other two books. Tuning the UDP transport, writing a language binding and running the smoke bench are in [the standard's book](/docs/guides/README.html); adding a stage to a ring, installing `pms`, running the daemon as a service, capturing envelopes, the MCP server, shared memory and troubleshooting are in [the daemon's book](/docs/daemon/guides/README.html). Adding a stage works the same way in the enterprise, HFT and robotics rings as in the dev ring the guide uses.
